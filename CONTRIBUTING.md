# Contributing to GridWorldRAG

## Development Setup

```bash
git clone https://github.com/GridWorldOrganization/GridWorldRAG.git
cd GridWorldRAG
./setup.sh
cp config.env.example config.env
# config.env に OAuth 認証情報を設定
```

## Pull Request

1. feature ブランチを作成
2. 変更をコミット
3. PR を作成し、変更内容を記述

## Code Style

- Python 3.12+
- PEP 8 準拠
- docstring は日本語 OK

## Issues

バグ報告・機能リクエストは [Issues](https://github.com/GridWorldOrganization/GridWorldRAG/issues) へ。
